# Video2Doc 3.1.0 验收记录

日期：2026-09-10。分支：`codex/prd-gateway-architecture`。

## 已交付行为

- 浏览器上传本地音频，任务保留自有副本、原文件名、大小和 SHA-256；校验空文件、格式、数量、大小与非法配置。任务缓存不删除上传副本，永久删除仅删除自有副本，用户原音频保持不变。
- 无文本模型的新建真实任务在完整初稿生成后进入待人工校对，释放队列。支持下载/复制初稿、复制提示词、粘贴/导入 UTF-8 Markdown/TXT 修改稿、保存后跨重启继续。
- 用户采用修改稿或直接使用初稿后，仅恢复文档导出。数字/专名缺失和异常删减有显式确认；保留初稿、用户决定、来源引用及自动校验结果。导出失败重试不重新转写。
- 字幕预检优先于整段视频下载；逐个尝试人工/自动字幕语言、JSON3 和 B 站备用接口，支持短链接和 av 链接；失败按配置回退内嵌字幕或 ASR。取消会终止在途 HTTP 请求。缓存不接受临时、越界、哈希不符或无法解析的字幕。
- 同时收录此前用户批准的鲁棒性修复、历史分页/增量更新、差异审阅与回收站功能。

## 验证边界
