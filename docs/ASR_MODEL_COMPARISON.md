## 内容、时间戳和稳定性观察

### Fun-ASR realtime 2026-02-28

**真实环境验证通过（当前普通话/中英混合片段）**

- 45 秒片段形成连续可读文本，没有整段丢失。
- 识别出 Chrome、cookie、profile、Eagle、Cloud Code、skill 等中英混合词；专有名词大小写或拼写仍可能需要轻度编辑。
- 2 个最终句段和 137 个词级时间戳覆盖 0.08–44.98 秒，未倒退。
- PCM 按原时间线发送，因此耗时接近实时；不能和离线模型按相同吞吐口径直接比较。
- 当前没有足够的四川口音/方言证据。
- 完整 542.3485 秒音频以单个会话完成，19 段、1,691 词，覆盖 0.12–542.34 秒；segment/word 时间戳倒退均为 0，精确重复句段为 0。
- 真实取消约 4.109 秒结束，没有保存 normalized 输出或晚到结果；网络恢复与拆分会话仍待真实故障验证。

### Whisper large-v3

**真实环境验证通过（短音频）**

- 语言检测为 zh；得到 6 个句段和 212 个词时间戳。
- 45 秒音频墙钟 34.983 秒，其中首次加载 20.501 秒；观察峰值 8,415 MiB。
- 中文和中英混合内容连续可读；产品名存在常见同音/大小写差异。没有人工参考稿，不能据此断言准确率优于其他模型。

### FireRedASR2-AED

**真实环境验证通过（短音频和完整本地视频）**

- 官方 Python API、官方权重和 GPU half 推理均已实际运行；45 秒片段墙钟 41.186 秒，其中首次加载 34.036 秒。
- 短片段得到 1 段、223 个词级时间戳，覆盖 0.0–45.0 秒；segment confidence 为 0.98，模型未返回语言，因此保持 `null`。
- 显存从 1,958 MiB 上升到峰值 5,642 MiB（+3,684 MiB），明显低于本机 Qwen ASR + Aligner 同载峰值，但没有把这一资源差异解释为准确率优势。
- 完整视频以 55 秒块长和 5 秒重叠形成 11 块，模型请求 74.004 秒；最终 11 段、2,762 个词，segment 覆盖和非空词时间戳倒退均为 0。
- 10 个长重叠前缀和 1 组精确词重叠在结构化层消除；7 个无法确定的边缘词保留文本、时间置 `null`。retry 复用 11/11 成功块，取消在生成 2 块后停止。

### Qwen3-ASR-1.7B + ForcedAligner

**真实环境验证通过（短音频和完整本地视频）**

- 45 秒中文/中英混合片段：1 段、227 个 ForcedAligner 词项，时间覆盖 0.0–44.96 秒且不倒退；墙钟 84.732 秒，其中首次加载 70.294 秒。
- 显存从 3,168 MiB 上升到峰值 9,635 MiB（+6,467 MiB），ASR 与 Aligner 可在本机 12 GiB GPU 同载，但剩余空间有限，不与其他大模型同时驻留。
- 完整视频按 180 秒块长和 5 秒重叠形成 4 块，首次真实运行总墙钟约 135.2 秒；最终重放合并后 4 段、2,751 个词项、非空词时间戳倒退 0、SRT segment 边界覆盖 0。
- 重叠层删除 3 组长相似前缀；1 个有冲突的边缘词保留文本并把时间置 `null`，避免伪造时间。179.64、355.52 和 530.04 秒附近均无明显边界重复或整段丢失。
- 当前素材证明中文和中英混合可运行；没有独立英语口语或四川口音参考样本，不提供 WER/CER 或方言准确率结论。

### Whisper large-v3-turbo

**真实环境验证通过（短音频、完整本地视频和 Bilibili 视频）**

- 短音频语言检测为 zh；5 个句段、217 个词，墙钟 10.795 秒，首次加载 8.942 秒。
- 9 分钟本地视频：22 块，最终重放合并 192 段、2,593 词；首次 ASR 请求约 30.461 秒。
- 31 分 31 秒 Bilibili 视频：76 块，最终重放合并 846 段、8,932 词；首次 ASR 请求约 125.811 秒。
- 两个完整任务均输出 TXT、SRT、normalized JSON 和原始响应，时间戳倒退为 0；重试全部复用成功块且没有再次写入重复段。
- 短音频峰值观察为 8,018 MiB，但测试是从 large-v3 切换而来，基线已经包含前一模型显存，不能把 0 MiB 增量解释为 turbo 不占显存。

## 分块、重叠和人工边界检查

离线模型使用能力驱动块长和 5 秒重叠。局部 segment/word 时间戳先映射到全局轴，再在重叠窗口按时间与规范化文本去重；不确定时保留内容并记录冲突。Fun-ASR 的单一连续 WebSocket 会话不创建重叠，也不重复发送音频。

| 素材 | 检查边界 | 结果 |
| --- | --- | --- |
| 9 分钟本地视频 | 25 秒 | 上下文连续，无明显重复、倒退或整段丢失 |
| 9 分钟本地视频 | 50 秒 | 识别词形存在差异；只删除确认重复词并保留冲突，没有整段重复或时间戳倒退 |
| 9 分钟本地视频 | 275 秒 | 语句连续，无明显重复、倒退或整段丢失 |
| Bilibili 视频 | 25 秒、50 秒 | 语句连续，无明显边界重复 |
| Bilibili 视频 | 500 秒 | 有轻微词形分裂；保留不确定内容，没有字幕重复、倒退或整段丢失 |
| FireRed 本地视频 | 50 秒、100 秒 | 跨词边缘保留；100 秒同源不同拼写重复已消除，无整段丢失 |
| FireRed 本地视频 | 500 秒 | “百度地图”等前一块未输出的边缘新词得到保留，时间戳不倒退 |

Whisper 本地视频最终诊断 56 条，确定删除 8 个重复 segment、18 组精确词重叠和 16 组长相似前缀，8 个冲突词保留文本但时间置 `null`；Bilibili 最终诊断 286 条，确定删除 50 个 segment、101 组精确词重叠和 34 组长相似前缀，66 个冲突词保留文本但时间置 `null`。FireRed 最终诊断 16 条，确定处理 11 组重叠，7 个边缘词保留但时间置 `null`。各结果的 segment 边界覆盖与非空词时间戳倒退均为 0；TXT、SRT 与 normalized JSON 均由同一结构化序列生成。

## 部署复杂度和当前限制

| 模型 | 部署复杂度 / 当前事实 |
| --- | --- |
| Fun-ASR | 无本地权重和显存压力，但依赖网络、密钥、实时 WebSocket 生命周期和云端限额 |
| FireRedASR2-AED | 官方提交、4.73 GB `model.pth.tar`、Python 3.11/CUDA 环境和真实推理均通过；依赖约束最严格，但本机峰值显存低于 Qwen 同载方案 |
| Qwen3-ASR + Aligner | Transformers 后端已真实同载；峰值 9,635 MiB，部署复杂度和首次加载时间均高于 Whisper worker，需单模型驻留 |
| Whisper large-v3 | faster-whisper 部署已通过，质量优先，首次加载和显存占用高于 turbo |
| Whisper large-v3-turbo | faster-whisper 部署已通过，当前真实素材上吞吐更高；不据无参考稿结果宣称质量优劣 |

四川口音适应性仍为 **未验证或失败**。没有合适标注样本时不会编造方言结论、WER 或 CER。
