# Video2Doc 应用使用手册

## 1. 启动

双击 `dist\Video2Doc-Portable\Video2Doc.exe`。应用优先使用 `127.0.0.1:8765`；若默认端口被 AnkiConnect 等其他程序占用，会自动选择后续空闲端口并打开正确地址。启动后显示独立应用窗口，点击右上角 X 即可关闭窗口和该窗口启动的后端。应用自动升级自己的数据库，数据默认位于 `%LOCALAPPDATA%\Video2Doc`。

首次使用先打开“应用设置”，点击“重新检查环境”，确认 FFmpeg、ffprobe 和 yt-dlp 可用。缺少工具或 Gateway 时界面会显示原因，不会把未完成任务伪装为成功。

## 2. 配置 Gateway

在“Gateway”页添加 ASR 或 OCR 服务：

1. 选择类型，填写名称、协议和 Base URL。
2. 如服务需要密钥，只填写环境变量名称，不填写密钥值。
3. 设置超时和重试次数。
4. 点击“连接测试”；支持发现的服务再点击“模型发现”，否则手工添加模型。
5. 内置的外部 Docker OCR 条目保存 `managed_lifecycle=false`；自定义外部 Gateway 也不会被应用停止。

本地 OCR 默认地址是 `http://127.0.0.1:8201`，协议是 `video2doc-ocr-http-v1`，模型是 `PP-OCRv5_server`。旧 PaddleOCR-VL 服务可使用 `paddlex-layout-parsing-v1` 适配协议。

## 3. 设置 Obsidian 与文本整理

在“应用设置”配置：

- 已存在的 Obsidian Vault 绝对路径；
- Vault 内的 Inbox 相对路径；
- 文件名、附件目录和追溯目录模板；
- 同名时自动改名、停止或带回滚覆盖；
- 是否保存 JSON sidecar、转写和字幕；
- 可选 OneAPI Base URL、文本模型和忠实性阈值。

不启用文本模型也能完成全部流程。启用后，模型只按块做错字、空白、标点和分段等轻度整理；响应缺失来源、异常缩短或损坏数字、代码、公式时自动拒绝并回退原文。

## 4. 新建任务

进入“新建任务”：

1. 选择“视频网页 URL”或“本地视频 / 音频”。
2. 本地输入可点击“选择本地媒体文件”，也可粘贴绝对路径；URL 和路径均可每行一个。
3. 选择文本来源：ASR，或“导入中文字幕（跳过 ASR）”。
4. 字幕模式选择一个 SRT、VTT、ASS、SSA 或 TXT 文件；字幕会复制到任务工作区，且一次只创建一个对应任务。
5. 选择处理方案，或覆盖 ASR/OCR Gateway 与模型。字幕模式不会调用方案中的 ASR 模型。
6. 视频任务可启用 OCR，并设置抽帧策略、间隔、场景阈值、候选数和融合窗口。
7. 选择是否启用 OneAPI 忠实轻度整理。
8. 选择本次任务的成品导出目录；留空时使用应用设置。
9. 点击“加入串行队列”。

应用按创建顺序单并发处理。所有耗时步骤在 Worker 中执行，关闭或刷新浏览器不会把 API 请求变成长任务。

## 5. 查看和控制任务

“任务详情”显示输入、不可变快照、attempt、错误、各阶段、媒体、ASR/导入字幕、帧/OCR、融合、Document、Markdown、产物和导出位置。每个阶段同时显示实际选用的 Gateway/模型；未调用模型的本地阶段会明确标注。

可用操作：

- 等待或运行任务：取消；
- 失败或中断任务：重试并复用指纹一致的有效产物；
- 任意已有工作区任务：打开任务工作区；
- 已导出任务：打开导出目录或最终 Markdown；
- 失败任务：复制错误信息。

取消会停止后续阶段并终止由 Video2Doc 启动的外部进程树。退出 Windows 应用时，运行任务保存为可恢复状态；独立 Docker OCR 不会被停止。

## 6. 结果检查

最终 Markdown 应有 YAML frontmatter、媒体来源、时长、模型/配置、正文、语音或字幕、画面文字、相对图片和追溯信息。成品默认不显示媒体时间戳，也不写入生成时间字段；原始 JSON/SRT 仍保留时间信息。附件和 `.data` sidecar 应与 Markdown 同名成组存在。

如结果不符合预期，优先在任务详情检查：

- attempt 和失败阶段；
- ASR/OCR 原始响应与 normalized 产物；
- 融合时间线和 Document source_id；
- `text_edit.json` 是否使用回退；
- `export.json` 的最终路径和冲突处理结果。

Video2Doc 不生成摘要、核心观点、复习提纲、自动问答、RAG、向量索引或知识库回答。
