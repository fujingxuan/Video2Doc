# Video2Doc 3.3.0 模型部署与链接修复验收

日期：2026-10-03。验收机器：Ryzen 9 9955HX、RTX 5070 Ti Laptop，12GB 显存。

## 实际修改

- FireRed 使用内存映射读取官方权重，通过 Accelerate 空参数初始化和 PyTorch `assign=True` 避免先初始化、再复制约 11.5 亿随机参数。严格检查完整权重，并恢复官方解码器共享的词嵌入参数。修改只在本次模型加载期间生效，未改写厂商安装目录。
- 优先使用 WSL 原生文件系统中的模型 Python 环境；缺失时兼容原有 D 盘环境。显式配置的环境目录仍优先。
- 本地 ASR Gateway 编辑页面可选择 NVIDIA CUDA 或 CPU，在下一次自动启动时生效。健康检查报告模型参数的实际设备、精度及加载／推理耗时；卸载时清空旧指标。CPU Whisper 默认使用 int8。
- 模型显示名称精简并附场景，技术模型 ID 不变。文本模型同样提供独立显示名称，调用原始模型 ID。
- 内置官方 yt-dlp 2026.08.19，下载后验证官方 SHA-256。此前系统安装版本为 2026.07.04。构建及更新脚本可复现该部署。
- 关闭 OCR 且直接使用 ASR 的链接任务优先下载最佳音频；需要画面或内嵌字幕的流程仍下载视频。下载器访问本机地址时显式绕过代理。
- 需要登录、不支持 URL 的下载错误转换成可操作的中文提示；可通过显式 Cookie 文件接入登录态，软件不读取浏览器 Cookie。

## 模型版本与更大模型

FireRedASR2-AED、Qwen3-ASR-1.7B、Qwen3-ForcedAligner-0.6B、Whisper large-v3、large-v3-turbo 的本地下载提交均与检查当日远端提交相同；没有重新下载这些最新权重。官方 FireRedASR2S 代码提交也与本地一致：`4e7d9aaf4482a47cec1724807026b9b151926eb5`。

Qwen 1.7B 加 0.6B 对齐器已经部署并完成真实 CUDA 推理，可作为参数量更大的现成选项。FireRed 2 适合中文及方言，Qwen3 适合多语和词级对齐，Whisper V3 适合多语质量优先，Turbo 适合快速转写。

[官方 FireRedASR2-LLM 实现](https://github.com/FireRedTeam/FireRedASR2S/blob/main/fireredasr2s/fireredasr2/asr.py) 还依赖 Qwen2-7B-Instruct。仅 7B 语言模型的半精度权重约需 14GB，另需音频编码器、缓存和运行空间，超出这台机器的 12GB 显存。本版本没有把未验收的量化版加入可用模型列表。4bit 量化属于进一步实验方案，尚未验证质量、显存和时间戳能力。

## CPU／核显／独显速度的原因

同一份 30 秒音频的实测如下。CPU 与 CUDA 输出的 FireRed 文本一致；这些是小样本性能记录，不代表所有媒体的固定速度。

| 路径 | 首次总耗时 | 模型加载 | 后续同样音频推理 |
|---|---:|---:|---:|
| FireRed CPU FP32 | 69.37 秒 | 33.26 秒 | 34.07 秒 |
| FireRed CUDA 优化前 | 45.22 秒 | 40.58 秒 | 0.99 秒 |
| FireRed CUDA 优化后 | 22.43 秒 | 17.42 秒 | 1.05 秒 |
| Qwen3 CUDA + 对齐器 | 58.85 秒 | 37.59 秒 | 1.33 秒 |

优化前后记录跨两次会话，磁盘缓存、首次 CUDA 初始化和机器负载会影响冷启动，不能把表格比例作为普遍加速保证。加载后的 FireRed CPU／CUDA 推理差距约 33 倍，速度差距并不小。下载、FFmpeg 处理、模型加载、CPU 特征提取、固定在 CPU 的 OCR、文本服务等待和人工校对都会稀释端到端的差距。

实际运行的 ASR 参数位于 `cuda:0`，精度 BF16；项目没有 AMD 核显 ASR 后端。任务管理器核显活动不能证明 ASR 在核显推理。FireRed 后续推理分配显存约 2246MiB、保留约 2682MiB；Qwen 加对齐器分配约 5684MiB、保留约 6152MiB。整卡占用还包含桌面等程序；显存余量不意味着模型参数可以自动变大。

## 历史链接错误

历史任务 18、19、20 均为同一个小红书短链接，重定向到登录页后，旧下载器报 `Unsupported URL`。新版下载器仍确认平台要求登录；用户没有可提供的 Cookie，因此不能验证该短链的登录态下载成功。

最终发行包对该链接返回 `MEDIA_LOGIN_REQUIRED`，说明可导入下载的音视频、可访问的媒体直链，或配置显式 Cookie 文件。匿名下载限制仍然存在，不能视作已经绕过。另一条小红书 CDN 直链在历史任务中已经成功，原来的失败不是 ASR 模型错误。

历史 FireRed 空文本错误的当前处理已通过无语音返回测试：空文本可作为无语音结果，真正的空结果列表仍报告推理错误。
