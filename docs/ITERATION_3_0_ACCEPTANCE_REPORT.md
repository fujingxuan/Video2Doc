# Video2Doc 3.0.0 验收报告

验收日期：2026-08-09

## 交付范围

- 队列任务可多选、单个删除或批量删除。
- 仅允许编辑尚未开始的排队任务；处理中任务必须先取消再删除。
- 删除任务时同时删除数据库记录、任务工作区和对应导出成品；原始本地输入文件始终保留。
- 新建任务自动恢复上一个任务的完整处理设置，但不复制上一个输入地址和标题。
- 页面改为低饱和墨绿色与暖灰色主题，补充键盘焦点、危险操作状态和窄屏布局。
- 后端、前端和便携版版本统一为 `3.0.0`。

## 删除安全边界

删除前会验证工作区位于记录的数据根目录内、目录名与任务 ID 一致，并校验 `task_state.json` 中的任务身份。导出文件也必须位于记录的导出根目录内；符号链接、路径越界和身份不匹配都会拒绝删除。处理中任务不会被直接删除，避免与 Worker 写入竞争。
